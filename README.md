# Cleaning Kompleks

Professional landing-page project for a cleaning services business.

## Status

The repository is configured with GitHub Actions validation and Vercel deployment integration.

## Development

The current repository is intentionally minimal. Add the application source, assets, and package configuration as they are introduced to the project.

Before opening a pull request, verify that the repository checks pass and that no secrets are committed.

## Deployment

Vercel is used for preview deployments from Git branches and for production deployment from `main`.

## Repository standards

- Keep production code and configuration deterministic.
- Keep secrets out of source control.
- Use focused pull requests with clear commit messages.
- Keep documentation aligned with the actual project structure.

See [CONTRIBUTING.md](CONTRIBUTING.md) for the contribution workflow.
